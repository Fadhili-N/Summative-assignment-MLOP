Malaria Cell Classifier

Upload a blood-cell image and the model says whether it looks parasitized. A study project, not a medical device.

Predict one cell image

Choose an image (.png or .jpg) and press Predict.

1. Upload new labelled images

Either a .zip with folders named Parasitized/ and Uninfected/, or several images plus a label.

2. Retrain the model

Starts from the current saved model and fine-tunes it on the uploaded images (mixed with some original images so it doesn't forget). The new model replaces the old one only if it isn't worse.
